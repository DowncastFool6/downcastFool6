## 🏗️ Featured Project — SOMP

**Service Operations Management Platform** — a full-stack internal web application for an IT services company, built entirely from scratch over a structured 30-day sprint.

| | |
|---|---|
| **Stack** | Laravel 11 · PHP 8.3 · Livewire v3 · MySQL 8 · Redis · Tailwind CSS v3 |
| **Scale** | 11 database tables · 22 Livewire components · 8 operational domains |
| **Auth** | 3 roles (Admin / Manager / Technician) via Spatie Laravel-Permission |
| **Features** | Ticket lifecycle enforcement · Encrypted equipment credentials · Equipment transfer audit log · Contract renewal tracking · Maintenance calendar · Role-scoped dashboard with Redis cache · In-app notifications · Excel exports |
| **Environment** | Laravel Sail · Docker · WSL 2 · Vite 5 |

> Built with strict domain-driven architecture, enforced state machines, and full role-based access control at the policy level.
